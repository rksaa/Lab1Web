1. Membuat Judul
<!-- judul utama -->
<h1>Belajar Dasar HTML</h1>
<!-- subjudul -->
<h2>Paragraf pada HTML</h2>

<!-- --> → digunakan untuk membuat komentar yang tidak tampil di browser.
<h1> → digunakan untuk membuat judul utama dengan ukuran terbesar.
<h2> → digunakan untuk membuat subjudul yang ukurannya lebih kecil dari <h1>.
Tag heading (<h1> sampai <h6>) digunakan untuk menyusun struktur dan hierarki judul pada halaman HTML, di mana <h1> adalah yang terbesar dan <h6> adalah yang terkecil.
