# Praktikum HTML Dasar

## Judul
Belajar Dasar HTML

## Tujuan
Praktikum ini bertujuan untuk memahami struktur dasar HTML serta cara menggunakan tag-tag penting dalam pembuatan halaman web.

## Alat dan Bahan
- Laptop
- Browser
- Editor teks atau VS Code
- File HTML dan gambar yang telah dibuat

## Langkah Kerja
1. Membuat dokumen HTML dengan struktur dasar `<!DOCTYPE html>`, `<html>`, `<head>`, dan `<body>`.
2. Menambahkan judul utama dan subjudul menggunakan tag `<h1>` dan `<h2>`.
3. Membuat paragraf dengan tag `<p>`.
4. Menambahkan format teks menggunakan `<b>`, `<i>`, dan `<strong>`.
5. Menambahkan rumus dan notasi matematika menggunakan `<sub>` dan `<sup>`.
6. Menyisipkan gambar dengan tag `<img>` dan atribut `src`, `width`, `alt`, serta `title`.

## Hasil
Halaman web yang dibuat menampilkan:
- judul utama dan subjudul,
- beberapa paragraf penjelasan,
- teks dengan format tebal dan miring,
- notasi kimia dan matematika,
- serta gambar profil mahasiswa.

## Kesimpulan
HTML merupakan bahasa markup dasar untuk membangun struktur halaman web. Dengan memahami tag-tag dasar, kita dapat membuat halaman yang sederhana tetapi terstruktur dengan baik dan mudah dibaca oleh browser.
