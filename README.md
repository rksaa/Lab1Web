## Penjelasan singkat file HTML ini

Kode di atas adalah contoh halaman web sederhana yang dibuat dengan HTML. Berikut fungsi utamanya:

- `<!DOCTYPE html>`  
  Menandakan dokumen ini adalah file HTML5.

- `<html lang="en">`  
  Membuka elemen utama HTML dan menentukan bahasa halaman, yaitu English.

- `<head>`  
  Berisi metadata halaman, seperti:
  - `<meta charset="UTF-8">` → mengatur karakter teks
  - `<meta name="viewport" ...>` → agar tampilan responsif di perangkat mobile
  - `<title>Document</title>` → judul halaman di tab browser

- `<h1>` dan `<h2>`  
  Digunakan untuk judul utama dan subjudul.  
  Contoh:
  - `Belajar Dasar HTML`
  - `Paragraf pada HTML`

- `<body>`  
  Bagian utama halaman yang akan ditampilkan di browser.

- `<p>`  
  Tag untuk paragraf teks.

- `<b>`  
  Membuat teks menjadi tebal.

- `<i>`  
  Membuat teks menjadi miring.

- `<strong>`  
  Menandai teks penting dengan penekanan lebih kuat.

- `<sub>` dan `<sup>`  
  Digunakan untuk menulis subscript dan superscript.  
  Contoh:
  - H<sub>2</sub>O
  - x<sup>2</sup>

- `<img src="images/profil.jpeg" ...>`  
  Menampilkan gambar.  
  Atribut penting:
  - `src` → lokasi file gambar
  - `width` → lebar gambar
  - `alt` → teks alternatif jika gambar tidak tampil
  - `title` → judul saat mouse diarahkan ke gambar
